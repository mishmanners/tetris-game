# Tetris

A super lightweight, single-file, web-based Tetris game. No build step, no dependencies — just open `index.html` in a browser.

## Play

Open [index.html](index.html) directly in your browser, or serve the folder with any static file server.

## Controls

| Key | Action |
| --- | --- |
| ← / → | Move left / right |
| ↑ | Rotate |
| ↓ | Soft drop |
| Space | Hard drop |
| P | Pause / resume |

## Features

- 7-bag piece randomizer with a next-piece preview
- Scoring, line clears, and level-based speed-up
- Pause and game-over overlay with restart
